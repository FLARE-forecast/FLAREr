# Get file path for driver forecasts

Get file path for driver forecasts

## Usage

``` r
get_driver_forecast_path(config, forecast_model)
```

## Arguments

- config:

  flare configuration object

- forecast_model:

  name of forecast model (i.e "noaa/NOAAGEFS_1hr); path relative to
  driver directory.

## Value

full path to driver forecast
